# Life-course competency questions

Each population pack contributes at least 13 original natural-language
questions. Expected results are normalized discovery records, not generated
answers or personal decisions.

`scripts/check_search_acceptance.py` verifies canonical titles and registered
aliases in the first five, each competency question's expected family in the
first ten, staged process retrieval and empty results for an unmatched query.
